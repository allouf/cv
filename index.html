المساهمة في منصة بلوكتين مُصرَّح بها لتتبع توزيع القمح عبر خمس جهات — تجار الجملة، الموزعون، تجار التجزئة، والمفتشون الحكوميون. كتابة chaincode بلغة Go (عقود ذكية) تفرض قواعد النقل والتحقق بين كل جهة، بحيث يمكن التحقق من الملكية والحضانة في كل مرحلة. إعداد شبكة Hyperledger Fabric — القنوات، المؤسسات، الأقران، وخدمة الترتيب — وإعداد نشر Docker/YAML. بناء واجهات الويب لكل جهة لتسجيل والاستعلام عن التحويلات على السجل.

محفظة Web3 متعددة الشبكات

بناء محفظة Web3 متعددة الشبكات بـ JavaScript باستخدام Web3.js وواجهات MultiChain — تدعم إدارة الحسابات، توقيع المعاملات، تتبع الأرصدة، تبديل الشبكات، وسجل المعاملات من واجهة واحدة. تنفيذ طبقة فهرسة محلية لتخزين معاملات المحفظة الخاصة للبحث السريع في السجل.

PumpBNB — منصة إطلاق رموز على BNB Chain: منصة بدون كود لإنشاء وتداول رموز الميم على BNB Chain. تتداول الرموز وفق نموذج منحنى ربط آلي حتى تصل إلى حد سوق معين، ثم تُرحَّل السيولة إلى PancakeSwap وينتقل الرمز إلى التداول المفتوح. تصميم وتنفيذ العقود الذكية وواجهة برمجة التداول وواجهة الويب من البداية للنهاية.

FlipCoin — لعبة رمي عملة عادلة على Solana: لعبة رهان بين لاعبين حيث يمكن التحقق من نتيجة رمي العملة على السلسلة. بناء برنامج Solana باستخدام بروتوكول إلتزام وكشف مع عشوائية قابلة للتحقق، إضافة إلى واجهة الويب ولوبي اللعبة الفوري.

تطبيق توليد الأفكار الصوتي (Android + Wear OS): تطبيق من جزأين — تطبيق موبايل مع ساعة Wear OS مرافقة. يلتقط المستخدمون الأفكار صوتياً على الساعة أو الهاتف؛ ينقل التطبيق الصوت بـ Whisper، ويعالجه بـ OpenAI (Chat Completion)، ويعيد اقتراحات منظمة وواعية بالسياق في الوقت الفعلي. بناء جسر Android–Unity، وتطبيق Wear OS المرافق مع مزامنة الحالة عبر Wearable Data API، وطبقة تكامل OpenAI.

المعهد العالي للعلوم التطبيقية والتكنولوجيا (HIAST) · دمشق، سوريا

تدرّجت على مدى 15 عاماً من مطوّر شامل إلى مهندس أول إلى مشرف على الأعمال، مسؤولاً عن تسليم أنظمة إنتاجية لوزارات حكومية سورية ومؤسسات القطاع العام. كجزء من فريق هندسة Full-Stack، شاركت في تحليل المتطلبات وتصميم النظام، ثم توليت ملكية وحدات محددة — من التنفيذ والاختبار إلى النشر والصيانة وتدريب المستخدمين. في السنوات اللاحقة، أشرفت على تسليم عدة مشاريع متزامنة ونسّقت مهام الفريق.

  • نظام إدارة الثروة الحيوانية — وزارة الزراعة: نظام متكامل لتتبع سجلات الثروة الحيوانية واللقاحات وسجلات المزارع في المحافظات، مع صلاحيات للأطباء البيطريين الميدانيين والإدارة المركزية. المساهمة في تصميم قاعدة البيانات ومنطق جدولة اللقاحات والتقارير الإحصائية. ASP.NET, C#, SQL Server.
  • نظام التعداد والبيانات التخطيطية — وزارة الزراعة: منصة جمع بيانات وتخطيط تدعم التعداد الزراعي الوطني وتخطيط الموارد عبر المناطق. المساهمة في نموذج البيانات ونماذج الإدخال، وبناء تقارير التخطيط، وتطوير أدوات ETL لنقل بيانات دورات التعداد السابقة من ملفات التصدير القديمة إلى قاعدة Oracle الجديدة — شاملةً المطابقة والتحقق والتسوية. Java JSF, PrimeFaces, Oracle DB.
  • نظام توزيع المهندسين الخريجين على الوظائف العامة: نظام معلومات لإدارة تعيين المهندسين الخريجين حديثاً في الوظائف الحكومية، يشمل قواعد الأهلية والتفضيلات ومنطق الترتيب والتقارير الرسمية للتعيين. Oracle DB, Java / PrimeFaces.
  • منصة التحليلات التعليمية الوطنية — وزارة التعليم العالي والبحث العلمي: بحيرة بيانات حكومية توحّد بيانات الطلاب والمؤسسات والمنح والاعتماد عبر الجامعات التي تُبلّغ عبر أنظمة Oracle و SQL Server قديمة. بناء خطوط أنابيب Python للاقتطاع إلى S3/MinIO، نمذجة المستودع في BigQuery باستخدام dbt (staging → marts, snapshots, tests)، تنسيق العمليات بـ Airflow، واستخدام PySpark + Delta Lake لاستبعاد تكرار سجلات الطلاب عبر المؤسسات. Python · SQL · dbt · Airflow · BigQuery · PySpark · Delta Lake · S3/MinIO · Oracle · SQL Server · Docker · Metabase · GitHub Actions.
  • أنظمة المختبرات الحكومية وإصدار الشهادات — وزارة التجارة: تتبع عينات المختبر والنتائج وإصدار الشهادات آلياً بما حسّن زمن إنجاز المعاملات. بناء شاشات تسجيل العينات وإدخال النتائج وتوليد الشهادات وطباعتها آلياً. Java JSF, PrimeFaces, Oracle.
  • نظام تتبع المركبات GPS: منصة متكاملة — تطبيقات Android للسائقين، خدمات Java خلفية، لوحة تحكم ExtJS للتتبع الحي وسجل الرحلات، و REST API يربطها جميعاً. المشاركة في ترحيل الزبائن الحاليين من منصات تتبع سابقة — مطابقة وتحويل بيانات الزبائن والمركبات والأجهزة والسائقين، استيرادها على دفعات مضبوطة، ومعالجة السجلات المكررة والمتعارضة (IMEI و SIM وارتباط الأجهزة) قبل الإطلاق. Android, Java, ExtJS, REST API.
  • نظام إدارة المخزون والمستودعات: إدارة مستودعات ومخزون مبنية على Oracle Database مع أدوات Oracle Developer — حركات المواد، فهارس الأصناف، وتقارير الجرد والتدقيق. Oracle DB, Oracle Developer.

Invest for All · دمشق، سوريا · دوام جزئي

عملت كجزء من فريق يبني نظام معلومات المستشفيات (HIS) باستخدام منصات مفتوحة المصدر (dcm4chee PACS و OpenEMR) وساهمت في تطوير RIS مخصص. تولى الفريق تحليل المتطلبات وتصميم النظام والنشر والتكامل مع أجهزة التصوير الطبي الحقيقية في المستشفيات.

المساهمات الرئيسية:

  • التشغيل البيني بين PACS/RIS/EMR — المشاركة في هندسة التشغيل البيني الكامل بين PACS و RIS و EMR عبر معايير DICOM و HL7، بما في ذلك قائمة عمل الأجهزة (MWL) وإدخال أوامر HL7 ORM وتقارير ORU ومزامنة حالة الفحص في الاتجاهين.
  • التقييم التقني — المساهمة في تقييم تخزين DICOM SCP/SCU و WADO وملفات IHE للتكامل.
  • النشر والإعداد — المشاركة في إعداد PACS جاهز للإنتاج على Linux مع JBoss/WildFly وربط أجهزة التصوير الحقيقية (CT، MRI، US).
  • تطوير RIS مخصص — المساهمة في تطوير وحدات RIS المخصصة.
  • التوثيق — إنتاج دلائل النشر والنماذج الأولية للتكامل الجاهزة للنشر على مستوى المستشفيات.
